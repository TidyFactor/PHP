## ⚡ راه‌اندازی سریع (Quickstart)

```bash
# نصب و اجرای مستقیم از طریق NPX
npx @tidyfactor/cli-php
```

یا فراخوانی مستقیم در دستیار برنامه‌نویسی (*Google Antigravity, Claude Code, Cursor, Codex*):
```text
/tidyfactor-php
```

## 📋 ماتریس دستورات اصلی

| دستور | هدف و نتیجه | جریان کاری (Workflow) |
|---|---|---|
| `/brief` | Arquitectura modular y configuración de módulos | `workflows/brief.md` |
| `/init` | Scaffolding de monolito Flight + Medoo | `workflows/init.md` |
| `/admin` | Módulos de administración y RBAC | `workflows/admin.md` |
| `/plugins` | Sistema de hooks y plugins desacoplados | `workflows/plugins.md` |
| `/themes` | Motor de temas dinámicos con Plates | `workflows/themes.md` |
