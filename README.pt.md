## ⚡ Início Rápido (Quickstart)

```bash
# Instalação e execução via NPX
npx @alwkala/tidyfactor-php
```

Ou execute diretamente dentro do seu assistente de IA (*Google Antigravity, Claude Code, Cursor, Codex*):
```text
/tidyfactor-php
```
